# Margin Exporter

A client-side web tool for browsing and exporting annotations, highlights, and bookmarks from [margin.at](https://margin.at) using the AT Protocol.

[Learn how to use it →](about.html)

## Features

- Browse margin.at collections in a clean, filterable interface
- Export in JSON, CSV, Markdown, or Beautified Markdown
- Filter by annotation type, tag, and date range
- Select specific annotations for export
- Full account backup
- No server, no build tools, no dependencies

## Quick start

Click [here](https://agilebuckle.github.io/margin-exporter) to open.
